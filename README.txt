# Moonbyul Portfolio (HTML, CSS, JavaScript)

## Run locally
1. Extract the ZIP.
2. Open the `moonbyul-portfolio` folder in VS Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.

## Customize before publishing
- The page is aligned to Jorilyn A. Paculdo’s supplied résumé. Review every section and adjust any detail before publishing.
- Add your own portrait at `images/profile.jpg` (portrait orientation recommended). The site shows a placeholder until the file exists.
- In `index.html`, update education, experience, project descriptions, certificates, LinkedIn and GitHub URLs.
- In `script.js`, replace `your.email@example.com` with your actual public contact email.
- Remove any skills you have not used or label them as currently learning.
- Project summaries are based on the supplied résumé. Add only approved public images, repository links, or case studies, and do not disclose confidential manufacturing information.
- Add links to your real project repositories and demos. Do not publish confidential company data, code, screenshots, or credentials.

## Contact form
The form uses a `mailto:` link and opens the visitor's default email application. It does not send messages directly from the website. A real web form that submits without an email app requires a backend or form service.

## Files
- `index.html` — content and sections
- `index.css` — layout, globe background, responsive styles
- `script.js` — navigation, project filters, and mailto form
- `images/` — place your profile photo here


Dock behavior
- On desktop, drag the empty background area of the left navigation dock up or down. Avoid dragging on the icon links or hide button because those remain clickable.
- Desktop content spacing has been increased so the dock does not cover the hero text.
